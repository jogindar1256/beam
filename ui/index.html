Direct Wi-Fi hotspot

No shared Wi-Fi? One computer starts a hotspot, the other joins it. Traffic goes straight between the two, with no router in between. Faster still: an Ethernet cable between PC and Mac (USB-C-to-Ethernet adapter if a computer has no port), or a Thunderbolt cable between two Macs. A plain USB-C cable between a PC and a Mac does not create a network.

On the other computer: Beam → Join hotspot → Scan → click this network, then type the password.
